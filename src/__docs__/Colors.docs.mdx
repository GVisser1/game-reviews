Components use colour roles, like `bg-surface` or `text-muted`, never palette shades like `gray-700`. Each role has a
light and a dark value, so dark mode comes for free. Everything on this page is read from `src/index.css`, so it always
matches the stylesheet.

## Roles

Each role works with every colour utility: `bg-accent`, `text-accent`, `border-accent` and so on.

## Adding a role

1. Add its light and dark value to `:root` in `src/index.css`, like `--name: light-dark(var(--gray-50), var(--gray-900))`.
2. Map it in the `@theme inline` block, like `--color-name: var(--name)`. It then shows up on this page.
3. If it's for text, or sits behind text, add its pairs to `src/docs/contrastPairs.ts`.
